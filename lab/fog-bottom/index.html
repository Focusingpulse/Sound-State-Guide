What this is

Sound State Guide is a plain-language guide to sound-based tools, brainwave entrainment, and the lineage the work comes from.

Nothing here is sold as a treatment. The point is understanding, so you can judge a tool instead of being carried by it.

The five states

Delta, theta, alpha, beta, gamma. Five named ranges, and most people already move through all of them every day without knowing the names.

Learning the names is not the useful part. Learning that you can move between them on purpose is.

What the evidence actually says

Some of this is well studied. Some of it is thinner than the marketing suggests. Both belong on the page.

Where the evidence is mixed, this site says so, because a tool you understand is worth more than a tool you believe in.

Where to start

Pick one thing. Use it for a week. Notice what changed, if anything. That is a better test than any claim on this page.

If it helps, keep it. If it does not, drop it without guilt. Either answer is useful information about you.
